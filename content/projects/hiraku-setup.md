## Sobre

Este repositório reúne as quatro configurações (Vim, Neovim, terminal e tmux) para instalar tudo de uma vez.
Com instalador visual no terminal para facilitar sua instalação. Pensado para ser usado nos mais diversos computadores, mantendo a consistência do workflow. Você pode instalar até em uma máquina em que seu usuário não tem  sudo.

## Instalação

```bash
git clone https://github.com/IcaropLira/HirakuSetupManager
cd HirakuSetupManager
chmod +x install.sh
./install.sh
```
