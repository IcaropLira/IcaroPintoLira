## Sobre

O **Mr. C++** é uma biblioteca de algoritmos e estruturas de dados em C++ voltada para programação competitiva, acompanhada de uma plataforma web interativa desenvolvida com React, TypeScript e Vite.

Você pode acessar a documentação online em **[mrcpp.vercel.app](https://mrcpp.vercel.app/)** ou explorar o repositório no GitHub em **[github.com/IcaropLira/MrCpp](https://github.com/IcaropLira/MrCpp)**.

## O que contempla

Todo o conteúdo é estruturado com base nos tópicos clássicos do *Competitive Programmer's Handbook* (CPH) de Antti Laaksonen, reunindo implementações limpas, testadas e de alta performance:

- **Fundamentos & STL:** Análise assintótica, complexidade, ordenação, busca binária e estruturas essenciais da biblioteca padrão.
- **Estruturas de Dados:** Vetor de prefixos, Fenwick Tree (Binary Indexed Tree), Segment Tree tradicional, Lazy Propagation, persistência e técnicas offline (Mo's algorithm).
- **Programação Dinâmica:** Definição de estados e transições, Maior Subsequência Crescente (LIS $O(n \log n)$ e via SegTree), Problema da Mochila (Knapsack), Subsequência Comum Mais Longa (LCS) e DP em árvores.
- **Árvores & Grafos:** DFS, BFS, Lowest Common Ancestor (LCA), Euler Tour, intervalos de entrada e saída (`tin`/`tout`), consultas em subárvores, componentes conexas, caminho mínimo (Dijkstra, Bellman-Ford, Floyd-Warshall) e fluxo.
- **Strings:** Trie com suporte customizado de alfabeto, cálculo de frequências de prefixos, Hashing polinomial com múltiplos primos, KMP, Z-algorithm e Aho-Corasick.

## Destaques da Plataforma

- **Documentação 100% interativa:** Cada algoritmo conta com explicação teórica, complexidades de tempo e espaço, notas de implementação e código completo pronto para copiar.
- **Padrões para competição:** Código padronizado em C++17 com `bits/stdc++.h`, tipos de 64 bits (`long long`) e otimizações de I/O rápido.
- **Busca em tempo real:** Encontre qualquer algoritmo ou estrutura instantaneamente pelo nome, tag ou complexidade.
