## Sobre

App desktop (Tauri) que lê um vault de notas, edita fichas e sincroniza com o Git. Gera instaladores para Linux (DEB, RPM e AppImage), Windows (MSI e NSIS) e macOS (DMG).

## Destaques

- Escolha da pasta do vault, com a última pasta lembrada
- Aba Git com sincronização (`fetch` e `pull --rebase --autostash`)
- Releases automáticos por tag `v*` com GitHub Actions
